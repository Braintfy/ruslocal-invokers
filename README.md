# Русификатор Invokers: Titan Legacy

Неофициальный русский перевод интерфейса игры. Проект не связан с HitZone Inc.

[English](README.en.md) · [Скачать последний релиз](https://github.com/Braintfy/ruslocal-invokers/releases/latest)

## Поддержка

| Платформа | Статус |
| --- | --- |
| Windows PC | Поддерживается |
| macOS, нативный клиент | Поддерживается |
| Android | Пока не поддерживается, сделаем позже |
| iOS / iPadOS | Пока не поддерживается, сделаем позже |

Сейчас распространяются только сборки для Windows и macOS. Старые Android-инструменты в репозитории оставлены для будущей доработки и не считаются готовым продуктом.

## Установка

### Windows

1. Скачайте Windows-установщик из [Releases](https://github.com/Braintfy/ruslocal-invokers/releases/latest).
2. Полностью закройте игру и лаунчер.
3. Запустите русификатор и нажмите **«Установить перевод»**.

### macOS

1. Установите и один раз запустите нативный клиент **Invokers Titan Legacy**.
2. В официальном лаунчере и в игре выберите **украинский язык**, дождитесь его загрузки и полностью закройте игру (`Cmd+Q`). Русский текст использует украинский языковой слот.
3. Перетащите **«Русификатор Invokers»** в «Программы», при первом запуске нажмите по нему правой кнопкой → **«Открыть»**.
4. Нажмите **«Установить перевод»**. Приложение покажет найденный клиент, версию игры и каталог, который будет изменён.

После установки не открывайте выбор языка: клиент повторно скачает официальный файл и сотрёт перевод. Если игра обновилась или язык переключили, просто установите перевод ещё раз.

Кнопка **«Открыть игру»** в Mac-руссификаторе запускает нативный клиент с `uk_UA`, чтобы официальный лаунчер не вернул английский слот аргументом `-language en_US`.

## Что изменяется

Русификатор собирает локализованный `dl_uk_UA.bin` из файлов установленной игры и открытого каталога перевода. Изменяется только пользовательский кэш локализации; исполняемые файлы, подпись и защита игры не затрагиваются. Перед заменой создаётся проверенная резервная копия, доступна кнопка **«Восстановить оригинал»**.

Актуальный каталог нативного Mac-клиента:

```text
~/Library/Application Support/hitzone.anima.spirit.guardians/i18n/
```

## Разработка

Требуется .NET SDK из `global.json`.

```bash
dotnet build InvokersRu.sln -c Release
scripts/test-mac-patcher.sh
scripts/build-mac-app.sh
```

Структура проекта и технические детали: [docs/](docs/). История изменений: [CHANGELOG.md](CHANGELOG.md).

Перевод любительский и может содержать неточности. Используйте на свой риск.
