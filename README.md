# Русификатор Invokers: Titan Legacy

Любительский перевод игры на русский язык. Переведено **41 037 строк из 41 292** — весь интерфейс: меню, задания, описания навыков, предметы, боевые сообщения. На английском остаётся одна строка, ещё 254 пусты в самой игре.

Перевод машинный, вычитки живым редактором не было. Игровые файлы проект не распространяет: русский текст собирается на вашем компьютере из ваших же файлов игры.

## Установка на Android

Перевод на Android работает и проверен, но способ установки зависит от телефона — так устроен сам Android, а не проект.

**Если на телефоне есть root** — скачайте APK, установите, нажмите «Установить перевод». Больше ничего не нужно.

**Если root нет (это обычный случай)** — перевод ставится с компьютера по кабелю. Приложение на самом телефоне сюда не поможет: начиная с Android 11 система не разрешает одному приложению читать и изменять файлы другого, и обойти это без root нельзя. APK всё равно стоит поставить — он покажет пошаговую инструкцию и откроет нужные разделы настроек.

Порядок установки с компьютера:

1. **Включите режим разработчика.** Раздела «Для разработчиков» в настройках сначала нет, он скрытый: «Настройки» → «Сведения о телефоне» → «Сведения о ПО» → семь раз подряд нажмите на «Номер сборки» и введите пин-код.
2. «Настройки» → «Параметры разработчика» (в самом низу списка) → включите **«Отладка по USB»**.
3. В игре выберите **украинский** язык, дождитесь загрузки и полностью закройте игру.
4. Подключите телефон кабелем и разрешите отладку во всплывающем окне на телефоне.
5. Запустите русификатор на Mac — он сам увидит телефон и предложит выбрать, куда ставить.

На Samsung сначала выключите **Auto Blocker** («Настройки» → «Безопасность и конфиденциальность»): он по умолчанию блокирует подключение по USB. На Xiaomi нужен ещё один переключатель — «Отладка по USB (настройки безопасности)».

Из терминала то же самое делает `scripts/android-patch.sh` с командами `status`, `apply`, `restore` и `reset`.

Подробный разбор, почему именно так: [docs/android-client.md](docs/android-client.md).

## Установка на macOS

1. Откройте DMG и перетащите **«Русификатор Invokers»** в папку «Программы».

2. **Первый запуск — правой кнопкой по значку → «Открыть»**, затем подтвердите. Обычный двойной клик система заблокирует: у приложения нет платной подписи Apple. Это нужно сделать один раз.

3. Запустите игру, зайдите в настройки и выберите **украинский** язык. Дождитесь загрузки и полностью закройте игру (Cmd+Q).

   Русский текст подставляется в украинскую ячейку — она единственная кириллическая в игре.

4. Запустите русификатор и нажмите **«Установить перевод»**.

5. Приложение попросит **доступ к данным игры** и само откроет нужный раздел настроек. Включите переключатель напротив «Русификатор Invokers» — установка продолжится сама, возвращаться в приложение не нужно.

   Если переключателя нет в списке, нажмите «+» и выберите приложение в папке «Программы».

## Одно правило, которое нельзя нарушать

**Не открывайте выбор языка в настройках игры.**

При выборе любого языка клиент заново скачивает языковой файл с сервера и стирает перевод. Язык должен остаться украинским. Если перевод внезапно пропал — почти всегда причина именно в этом; просто установите его заново.

## Обновления

Русификатор **обновляется сам**. При каждом запуске он проверяет репозиторий и подтягивает свежий перевод и свежую версию себя.

Переустанавливать приложение и заново выдавать доступ к диску не нужно: обновляемая часть лежит вне приложения, а подпись самого приложения остаётся неизменной. Загруженное обновление принимается только если его контрольная сумма совпадает с опубликованной.

Отключить самообновление можно так:

```sh
touch ~/Library/Application\ Support/InvokersRu/no-self-update
```

Скачивать новый DMG нужно редко — только когда приложение прямо об этом скажет. Так бывает, если менялся сам запускающий модуль. В этом случае разрешение на доступ к диску придётся выдать заново: система привязывает его к конкретной сборке. Достаточно в списке «Полный доступ к диску» выделить строку, нажать **«−»**, затем **«+»** и выбрать приложение заново.

## После обновления игры

Обновление игры сбрасывает перевод. Запустите русификатор и нажмите «Установить перевод» ещё раз.

Если игра обновила и сам текст, часть строк может временно остаться английской, пока перевод не адаптируют под новую версию.

## Как вернуть оригинал

Кнопка **«Восстановить оригинал»** в приложении. Перед изменением создаётся резервная копия с проверкой контрольной суммы, поэтому откат работает всегда.

Чтобы удалить русификатор полностью: нажмите «Восстановить оригинал», удалите приложение и папку `~/Library/Application Support/InvokersRu`.

## Риски

- Перевод машинный. Формулировки могут быть неточными, особенно в описаниях механик. Числа, проценты и длительности сохраняются в точности — их проверяет автоматический контроль.
- Проект неофициальный и не связан с HitZone Inc. Актуальные правила игры требуют осторожности с изменением клиента; используйте на свой риск.
- Приложение изменяет ровно один файл — кэш локализации в папке данных игры:
  `~/Library/Containers/<UUID>/Data/Documents/i18n/dl_uk_UA.bin`
  Сама игра, её подпись и защита не затрагиваются: этот файл лежит вне подписанного пакета приложения.
- Приложению нужен полный доступ к диску — иначе macOS не даёт ему прочитать файлы игры.

Правовой статус описан в [NOTICE.md](NOTICE.md).

## Если что-то пошло не так

Журнал работы: `~/Library/Application Support/InvokersRu/patcher.log`. В нём видно, что именно не получилось.

Частые случаи:

| Симптом | Причина и решение |
| --- | --- |
| «Не удалось создать резервную копию» | Нет доступа к диску. Выдайте его в настройках; если переключатель уже включён — удалите строку кнопкой «−» и добавьте приложение заново. |
| «Украинский языковой файл ещё не загружен» | Язык в игре не переключён на украинский, либо файл не докачался. |
| Перевод пропал сам | Открывали выбор языка в игре или игра обновилась. Установите заново. |
| «Не удалось собрать перевод для этой версии игры» | Игра обновилась, перевод ещё не адаптирован. |

## Для разработчиков

Кросс-платформенный CLI на .NET 10 без внешних зависимостей.

```sh
dotnet build src/InvokersRu.Cli/InvokersRu.Cli.csproj -c Release
dotnet run --project src/InvokersRu.SmokeTests -c Release --no-build -- PATH_TO_PRIVATE_FIXTURES
```

Сборка macOS-приложения и образа:

```sh
./scripts/build-mac-app.sh
```

Скрипт сам считает контрольную сумму драйвера, прописывает её в `config/mac-patcher.json` и удаляет предыдущие образы.

### Как это устроено

Игра берёт актуальные таблицы локализации не из своего пакета, а из пользовательского кэша. Перевод подменяет только его.

Публичный overlay `translations/ru_RU.jsonl` не содержит исходного английского текста — только хэши строк и русский перевод:

```json
{"id":"16_HEX","source_sha256":"64_HEX","translation":"Русский текст","status":"draft"}
```

Поле `source_sha256` автоматически обесценивает перевод, если английская строка изменилась в новом обновлении игры.

Приложение устроено так, чтобы разрешение macOS не слетало: точка входа — неизменный бинарный `launcher`, а обновляемый драйвер лежит в `~/Library/Application Support/InvokersRu/runtime/`. Любая правка внутри пакета сменила бы его подпись и отозвала доступ к диску.

### Основные команды

```sh
InvokersRu.Cli inspect FILE                 # разбор LOC1
InvokersRu.Cli roundtrip FILE               # доказать побайтовую пересборку
InvokersRu.Cli cache-status                 # состояние кэша игры
InvokersRu.Cli cache-profile --output FILE  # снять профиль новой версии игры
InvokersRu.Cli jobs --english EN --output JOBS
InvokersRu.Cli import-results --english EN --jobs JOBS --results RES --output NEXT
InvokersRu.Cli validate --english EN --translations CAT --include-draft
InvokersRu.Cli build --english EN --base UK --translations CAT --output OUT --include-draft --raw
```

Подробности по формату, платформам и переводческому конвейеру: [docs/](docs/).

### Новая версия игры

1. Снимите профиль: `cache-profile --output config/runtime-cache-profile.<версия>.json`
2. Постройте diff по `source_sha256`: неизменённые переводы остаются, изменённые становятся устаревшими, новые уходят в `jobs`.
3. Переведите новые строки и влейте через `import-results`.

Оригинальные файлы игры (`*.bin`, `*.bin.br`, `manifest.dat`) в репозиторий не попадают.
