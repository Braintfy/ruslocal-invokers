# Русификатор Invokers: Titan Legacy

Неофициальный русский перевод интерфейса игры. Проект не связан с HitZone Inc.

[English](README.en.md) · [Скачать последний релиз](https://github.com/Braintfy/ruslocal-invokers/releases/latest)

## Поддержка

| Платформа | Статус |
| --- | --- |
| Windows PC | Поддерживается |
| macOS, нативный клиент | Поддерживается |
| Android | Пока не поддерживается, сделаем позже |

## Установка

### Windows

**Windows 3.1.14:** перевод обновлён для EN/UK `Prod_0.61.2_10`; сохранена поддержка EN `Prod_0.61.1_3` с UK `_3`, `_5` и `_7`. Каталог хранит прежние варианты текстов, чтобы свежий перевод не лишал старые файлы покрытия. Для совместимой ревизии без точного профиля патчер применяет совпадающую часть перевода, показывает покрытие и оставляет изменённые непереведённые строки английскими. Отсутствующие файлы, неподдерживаемый формат, отсутствие подходящих строк и проблемы резервной копии объясняются отдельно. Запись поддерживается только в стандартную папку текущего пользователя Windows; выбранную нестандартную папку можно проверить. Неизвестные или повреждённые файлы не перезаписываются. Ничего вручную удалять не нужно.

Если перевод уже установлен, патчер явно показывает это. Недоступность нового обновления не означает, что установленный перевод пропал.

1. Скачайте Windows-установщик из [Releases](https://github.com/Braintfy/ruslocal-invokers/releases/latest).
2. В игре выберите **украинский язык**, дождитесь загрузки, затем полностью закройте игру и лаунчер.
3. Запустите русификатор, нажмите **«Проверить»**, затем установите или обновите русификацию.

**После перехода на 0.61:** сначала выберите английский язык, полностью перезапустите игру и дождитесь главного меню. Затем повторите это с украинским языком и закройте игру и лаунчер. Так игра загрузит обе свежие таблицы, а не оставит английский файл от предыдущей версии.

**Обновление старого патчера:** версии 3.1.5–3.1.13 предложат установить **3.1.14** автоматически. Новый каталог с историческими вариантами требует 3.1.14; старый патчер сначала предложит обновить программу. Для версий 3.1.2–3.1.4 один раз запустите актуальный установщик поверх старой версии. После этого патчер при запуске и нажатии «Проверить» ищет новую версию программы в GitHub и предлагает установить её. [Прежняя прямая ссылка](https://github.com/Braintfy/ruslocal-invokers/releases/download/v3.1.2-preview/InvokersRu-3.1-Preview-3.1.2-preview-win-x64.exe) сохранена.

Обновление перевода по-прежнему загружается отдельно от программы. Для установки новых текстов нажмите «Обновить перевод», когда патчер предложит это действие. Технический журнал спрятан в «Подробности для поддержки»: его можно показать или скопировать одной кнопкой. Windows может предупреждать о неизвестном издателе: Authenticode-подпись пока отсутствует; подписанное описание обновления и SHA-256 проверяются отдельно.

При сообщении об изменении EN/UK после установки не удаляйте состояние или резервную копию вручную. Обновите патчер, заново загрузите официальный украинский язык через игру, закройте игру и лаунчер и повторите проверку. Если отказ остаётся, нажмите «Скопировать для поддержки» и отправьте сведения автору. Изменённые английские строки без актуального перевода остаются английскими: версия клиента сама по себе установку не запрещает.

Для сопровождающих проекта: [как публиковать автообновления патчера](docs/patcher-self-update.md).

### macOS

Для текущего нативного клиента проверены лаунчер `1.0.319`, игра `0.61.1506` и скачанные языковые таблицы `Prod_0.61.1_3`. Mac-оболочка `3.1.0` использует скрипт `2.11.0`; кнопка **«Проверить»** также проверяет обновление скрипта. Совместимая установленная оболочка получает скрипт и каталог перевода без ручной замены DMG.

Ревизии английской и украинской таблиц могут отличаться: каталог уже содержит, например, сочетание EN `Prod_0.61.1_3` / UK `Prod_0.61.1_5`. Патчер сверяет их общее семейство и проверяет строки при сборке.

DMG для Mac — в [отдельном релизе macOS](https://github.com/Braintfy/ruslocal-invokers/releases/tag/invokersru-update-channel-v1); его прежние прямые ссылки сохраняются.

1. Установите и один раз запустите нативный клиент **Invokers Titan Legacy**.
2. После крупного обновления откройте игру на **английском**, дождитесь главного меню и полностью перезапустите её на **украинском**. Дождитесь главного меню и закройте игру и лаунчер (`Cmd+Q`). Русский текст использует украинский языковой слот.
3. Перетащите **«Русификатор Invokers»** в «Программы», при первом запуске нажмите по нему правой кнопкой → **«Открыть»**.
4. Нажмите **«Проверить»**, затем **«Установить перевод»**. Приложение покажет найденный клиент, версию языковых таблиц и каталог, который будет изменён.

После установки не открывайте выбор языка: клиент повторно скачает официальный файл и сотрёт перевод. Если игра обновилась или язык переключили, просто установите перевод ещё раз.

Кнопка **«Открыть игру»** в Mac-руссификаторе запускает нативный клиент с `uk_UA`, чтобы официальный лаунчер не вернул английский слот аргументом `-language en_US`.

## Что изменяется

**Проверка защиты и риск блокировок.** Windows-патчер и Mac-скрипт проверяют выбранный кэш и найденную установку игры перед записью. Если найдены известные признаки античита или подписи/контрольные суммы языковых файлов, установка перевода останавливается. Не удаляйте найденные файлы и не отключайте защиту: отправьте подробности автору. На Mac восстановление доступно при закрытой игре и точном совпадении текущего файла с установленным переводом.

Это не «антибан»: неизвестные и серверные проверки, а также изменения правил игры невозможно надежно выявить по локальным файлам. Если папка клиента не найдена, проверяется только кэш; перечень проверенных путей доступен в подробностях Windows-патчера. Отсутствие найденных признаков не гарантирует отсутствие блокировки аккаунта. При объявленном разработчиками запрете воздержитесь от русификации. [Как устроена проверка](docs/game-protection-checks.md).

Русификатор собирает локализованный `dl_uk_UA.bin` из скачанных файлов игры и открытого каталога перевода. Изменяется только пользовательский кэш локализации; исполняемые файлы, подпись и защита игры не затрагиваются. Перед заменой создаётся проверенная резервная копия. **«Восстановить оригинал»** доступно, только пока текущий файл точно совпадает с переводом, установленным этим патчером: новый официальный файл не заменяется старой копией.

Актуальный каталог нативного Mac-клиента:

```text
~/Library/Application Support/hitzone.anima.spirit.guardians/i18n/
```

Требуется .NET SDK из `global.json`.

```bash

scripts/test-mac-patcher.sh
scripts/build-mac-app.sh
```
