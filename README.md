# Русификатор Invokers: Titan Legacy

Любительский перевод игры на русский язык. Переведено **41 037 строк из 41 292** — весь интерфейс: меню, задания, описания навыков, предметы, боевые сообщения. На английском остаётся одна строка, ещё 254 пусты в самой игре.

Перевод машинный, вычитки живым редактором не было. Игровые файлы проект не распространяет: русский текст собирается на вашем компьютере из ваших же файлов игры.

Версия для Mac обновляется сама. Помощник для телефона каждый раз берёт свежий перевод с сайта проекта. Версия для ПК несёт перевод внутри архива и работает без интернета, но проверяет, не появилось ли обновление.

Игра на Mac — это приложение для iPhone и iPad, а такие приложения App Store ставит только на компьютеры с процессором Apple Silicon (M1 и новее). На Intel-маках игры нет и быть не может. Сам русификатор запускается на любом Mac: на Intel он объяснит это словами, а если подключён телефон Android с игрой — предложит поставить перевод на него.

## Установка на Android

Перевод на Android работает и проверен. Способ установки зависит от того, есть ли на телефоне root — так устроен сам Android, а не проект.

Начиная с Android 11 одно приложение не может читать и менять файлы другого. Обойти это на самом телефоне можно только с root, поэтому без него в дело вступает компьютер. Собирает перевод при этом всё равно телефон — компьютер только передаёт файлы туда и обратно. Никаких сторонних программ ставить не нужно: помощник сам скачивает всё, что ему требуется.

### Способ 1 — только телефон (нужен root)

1. Скачайте и установите APK.
2. В игре выберите **украинский** язык, дождитесь загрузки текста и полностью закройте игру.
3. Откройте «Русификатор Invokers» и нажмите «Установить перевод», разрешите root-доступ.

### Способ 2 — без проводов, по Wi-Fi

Телефон и компьютер должны быть в одной сети Wi-Fi. На Windows этот способ надёжнее кабеля: для него не нужны драйверы.

1. Скачайте на компьютер `Rusifikator-Invokers-PC.zip` и распакуйте в любую папку.
2. Запустите **«Русификатор-Android.cmd»** на Windows или **«Русификатор-Android.command»** на Mac. На Mac в первый раз откройте его правой кнопкой → «Открыть».
3. Включите на телефоне режим разработчика. Этого пункта в настройках сначала нет, он скрытый: «Настройки» → «Сведения о телефоне» → «Сведения о ПО» → семь раз подряд нажмите на «Номер сборки» и введите пин-код.
4. «Настройки» → «Параметры разработчика» (в самом низу списка) → включите **«Отладка по Wi-Fi»**.
5. В программе выберите «по Wi-Fi». Она попросит адрес и код — их покажет телефон: «Отладка по Wi-Fi» → «Подключение устройства с помощью кода сопряжения». Код живёт около минуты.
6. В игре выберите **украинский** язык, дождитесь загрузки и полностью закройте игру.
7. Нажмите «Установить перевод». Дальше всё произойдёт само: экран телефона на секунду моргнёт приложением-сборщиком.

### Способ 3 — по кабелю

Шаги 1–2 те же. Дальше:

3. Включите режим разработчика (см. выше) и в «Параметрах разработчика» — **«Отладка по USB»**.
4. Подключите телефон кабелем. Кабель должен быть для передачи данных, а не только для зарядки.
5. На телефоне появится окно «Разрешить отладку по USB?» — поставьте галочку «Всегда разрешать» и нажмите «Разрешить».
6. В игре выберите **украинский** язык, дождитесь загрузки и полностью закройте игру.
7. В программе выберите «кабелем USB» и нажмите «Установить перевод».

На **Samsung** сначала выключите **Auto Blocker** («Настройки» → «Безопасность и конфиденциальность»): он по умолчанию блокирует подключение по USB. На **Xiaomi** нужен ещё один переключатель — «Отладка по USB (настройки безопасности)».

### Вернуть оригинал

В той же программе: пункт 2 вернёт сохранённую копию, пункт 3 удалит текст и заставит игру скачать оригинал с сервера.

Из терминала то же самое делает `scripts/android-patch.sh` с командами `status`, `apply`, `restore` и `reset`.

Подробный разбор, почему именно так: [docs/android-client.md](docs/android-client.md).

## Установка на ПК

Для игры, установленной на сам компьютер. Всё нужное лежит в архиве: и перевод, и обработчик файлов, поэтому интернет не обязателен.

1. Распакуйте архив целиком. Запускать прямо из окна просмотра ZIP нельзя — рядом со скриптом должны лежать остальные файлы.

2. В игре зайдите в настройки и выберите **украинский** язык. Дождитесь загрузки и полностью закройте игру.

   Русский текст подставляется в украинскую ячейку — она единственная кириллическая в игре.

3. Запустите **«Русификатор-ПК.cmd»** и выберите пункт 1.

Папка с данными игры ищется по наличию файла `dl_en_US.bin`, а не по жёсткому пути, поэтому переименование студии или продукта в новой версии игры ничего не сломает. Оригинал сохраняется в `%LOCALAPPDATA%\InvokersRu\backup` — он переживает удаление архива.

Меню можно обойти, если нужно из скрипта:

```
powershell -NoProfile -ExecutionPolicy Bypass -File install-pc.ps1 -Action install -Quiet
powershell -NoProfile -ExecutionPolicy Bypass -File install-pc.ps1 -Action restore -Quiet
```

## Установка на macOS

1. Откройте DMG и перетащите **«Русификатор Invokers»** в папку «Программы».

2. **Первый запуск — правой кнопкой по значку → «Открыть»**, затем подтвердите. Обычный двойной клик система заблокирует: у приложения нет платной подписи Apple. Это нужно сделать один раз.

3. Запустите игру, зайдите в настройки и выберите **украинский** язык. Дождитесь загрузки и полностью закройте игру (Cmd+Q).

   Русский текст подставляется в украинскую ячейку — она единственная кириллическая в игре.

4. Запустите русификатор и нажмите **«Установить перевод»**.

5. Приложение попросит **доступ к данным игры** и само откроет нужный раздел настроек. Включите переключатель напротив «Русификатор Invokers» — установка продолжится сама, возвращаться в приложение не нужно.

   Если переключателя нет в списке, нажмите «+» и выберите приложение в папке «Программы».

## Одно правило, которое нельзя нарушать

**Не открывайте выбор языка в настройках игры.**

При выборе любого языка клиент заново скачивает языковой файл с сервера и стирает перевод. Язык должен остаться украинским. Если перевод внезапно пропал — почти всегда причина именно в этом; просто установите его заново.

## Обновления

Русификатор **обновляется сам**. При каждом запуске он проверяет репозиторий и подтягивает свежий перевод и свежую версию себя.

Переустанавливать приложение и заново выдавать доступ к диску не нужно: обновляемая часть лежит вне приложения, а подпись самого приложения остаётся неизменной. Загруженное обновление принимается только если его контрольная сумма совпадает с опубликованной.

Отключить самообновление можно так:

```sh
touch ~/Library/Application\ Support/InvokersRu/no-self-update
```

Скачивать новый DMG нужно редко — только когда приложение прямо об этом скажет. Так бывает, если менялся сам запускающий модуль. В этом случае разрешение на доступ к диску придётся выдать заново: система привязывает его к конкретной сборке. Достаточно в списке «Полный доступ к диску» выделить строку, нажать **«−»**, затем **«+»** и выбрать приложение заново.

## После обновления игры

Обновление игры сбрасывает перевод. Запустите русификатор и нажмите «Установить перевод» ещё раз.

Если игра обновила и сам текст, часть строк может временно остаться английской, пока перевод не адаптируют под новую версию.

## Как вернуть оригинал

На Mac — кнопка **«Восстановить оригинал»** в приложении. На Android — пункты 2 и 3 в программе для компьютера. Перед изменением создаётся резервная копия с проверкой контрольной суммы, поэтому откат работает всегда.

Чтобы удалить русификатор с Mac полностью: нажмите «Восстановить оригинал», удалите приложение и папку `~/Library/Application Support/InvokersRu`.

## Риски

- Перевод машинный. Формулировки могут быть неточными, особенно в описаниях механик. Числа, проценты и длительности сохраняются в точности — их проверяет автоматический контроль.
- Часть текста приходит с сервера, а не из файла игры: витрина магазина, тексты акций и событий останутся украинскими. Изменить это со стороны клиента нельзя.
- Проект неофициальный и не связан с HitZone Inc. Актуальные правила игры требуют осторожности с изменением клиента; используйте на свой риск.
- Изменяется ровно один файл — кэш локализации в папке данных игры:
  на macOS `~/Library/Containers/<UUID>/Data/Documents/i18n/dl_uk_UA.bin`,
  на Android `/sdcard/Android/data/hitzone.anima.spirit.guardians/files/i18n/dl_uk_UA.bin`.
  Сама игра, её подпись и защита не затрагиваются: файл лежит вне подписанного пакета.
- На macOS приложению нужен полный доступ к диску — иначе система не даёт ему прочитать файлы игры. На Android нужна отладка по USB или Wi-Fi, её стоит выключить, когда перевод установлен.

Правовой статус описан в [NOTICE.md](NOTICE.md).

## Если что-то пошло не так

На macOS журнал работы лежит в `~/Library/Application Support/InvokersRu/patcher.log`.

| Симптом | Причина и решение |
| --- | --- |
| «Не удалось создать резервную копию» (Mac) | Нет доступа к диску. Выдайте его в настройках; если переключатель уже включён — удалите строку кнопкой «−» и добавьте приложение заново. |
| «Украинский текст ещё не загружен» | Язык в игре не переключён на украинский, либо файл не докачался. |
| Перевод пропал сам | Открывали выбор языка в игре или игра обновилась. Установите заново. |
| «Не удалось собрать перевод для этой версии игры» | Игра обновилась, перевод ещё не адаптирован. |
| Телефон не появляется в программе (Android) | Не включена отладка, не нажато «Разрешить» на экране телефона, либо на Samsung включён Auto Blocker. По кабелю на Windows могут не встать драйверы — тогда используйте способ по Wi-Fi. |
| «Файл текста уже кем-то подменён» (Android) | Перевод ставили другим способом, а оригинала у программы нет. Выберите пункт 3 — игра скачает оригинал сама. |
| «Телефон не ответил за пять минут» (Android) | Экран телефона был заблокирован. Разблокируйте его и повторите. |

## Для разработчиков

Кросс-платформенный CLI на .NET 10 без внешних зависимостей.

```sh
dotnet build src/InvokersRu.Cli/InvokersRu.Cli.csproj -c Release
dotnet run --project src/InvokersRu.SmokeTests -c Release --no-build -- PATH_TO_PRIVATE_FIXTURES
```

Сборка macOS-приложения и образа:

```sh
./scripts/build-mac-app.sh      # приложение и образ для macOS
./scripts/build-android-apk.sh  # APK без Gradle: aapt2, javac, d8, apksigner
./scripts/build-pc-helper.sh    # архив помощника для компьютера, APK кладётся внутрь
./scripts/build-pc-game-tool.sh # архив для игры на ПК: win-x64 CLI и каталог перевода внутри
```

Скрипт сборки macOS сам считает контрольную сумму драйвера, прописывает её в `config/mac-patcher.json` и удаляет предыдущие образы. Ключ подписи APK лежит вне репозитория, в `~/.config/invokersru/android-release.keystore`, и его нельзя терять: Android отвергает обновление с другой подписью.

### Как это устроено

Игра берёт актуальные таблицы локализации не из своего пакета, а из пользовательского кэша. Перевод подменяет только его.

Публичный overlay `translations/ru_RU.jsonl` не содержит исходного английского текста — только хэши строк и русский перевод:

```json
{"id":"16_HEX","source_sha256":"64_HEX","translation":"Русский текст","status":"draft"}
```

Поле `source_sha256` автоматически обесценивает перевод, если английская строка изменилась в новом обновлении игры.

Приложение устроено так, чтобы разрешение macOS не слетало: точка входа — неизменный бинарный `launcher`, а обновляемый драйвер лежит в `~/Library/Application Support/InvokersRu/runtime/`. Любая правка внутри пакета сменила бы его подпись и отозвала доступ к диску.

### Основные команды

```sh
InvokersRu.Cli inspect FILE                 # разбор LOC1
InvokersRu.Cli roundtrip FILE               # доказать побайтовую пересборку
InvokersRu.Cli cache-status                 # состояние кэша игры
InvokersRu.Cli cache-profile --output FILE  # снять профиль новой версии игры
InvokersRu.Cli jobs --english EN --output JOBS
InvokersRu.Cli import-results --english EN --jobs JOBS --results RES --output NEXT
InvokersRu.Cli validate --english EN --translations CAT --include-draft
InvokersRu.Cli build --english EN --base UK --translations CAT --output OUT --include-draft --raw
```

Подробности по формату, платформам и переводческому конвейеру: [docs/](docs/).

### Новая версия игры

1. Снимите профиль: `cache-profile --output config/runtime-cache-profile.<версия>.json`
2. Постройте diff по `source_sha256`: неизменённые переводы остаются, изменённые становятся устаревшими, новые уходят в `jobs`.
3. Переведите новые строки и влейте через `import-results`.

Оригинальные файлы игры (`*.bin`, `*.bin.br`, `manifest.dat`) в репозиторий не попадают.
