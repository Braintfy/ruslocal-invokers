# Русификатор Invokers: Titan Legacy

[English version](README.en.md)

Любительский перевод игры на русский язык. Переведено **41 037 строк из 41 292** — весь интерфейс: меню, задания, описания навыков, предметы, боевые сообщения. На английском остаётся одна служебная строка, ещё 254 пусты в самой игре.

Переводила модель, живой редактор текст не вычитывал. После первого прогона корпус правился по скриншотам из игры: единый словарь терминов вместо разнобоя, вычитка прозы и укорачивание подписей, не влезавших в интерфейс. Числа, проценты и длительности сверяются с оригиналом автоматически.

Игровые файлы проект не распространяет: русский текст собирается на вашем компьютере из ваших же файлов игры.

## Перевод на свой язык

Проект переводит на русский, но конвейер к языку не привязан. Если игра уже держит слот под ваш язык — а держит она четырнадцать, — перевод делается тем же путём, и игровые файлы для этого никуда не отправляются.

| Что нужно | Где взять |
| --- | --- |
| Пошаговый конвейер целиком | **[Community localization kit](community-localization-kit/README.md)** — от снятия слепка своей версии игры до установщика для Windows и образа для macOS |
| Промпты для модели | [перевод](community-localization-kit/prompts/translation.md), [вычитка](community-localization-kit/prompts/review.md) |
| Промпты, обкатанные на полном корпусе | [первичный перевод](prompts/translation-system.ru-v2.md), [ремонт полуанглийских строк](prompts/translation-repair.ru-v4.md), [вычитка прозы](prompts/translation-polish.ru-v4.md) |
| Шаблоны | [глоссарий](community-localization-kit/templates/glossary.example.json), [стайлгайд](community-localization-kit/templates/style-guide.example.md), [конфиг языка](community-localization-kit/templates/language-config.example.json) |
| Как это устроено внутри | [формат LOC1 и конвейер](docs/architecture.md), [переводческий процесс](docs/translation-workflow.md) |

Чего конвейер не умеет: он не добавляет в игру новых языков и не меняет её формат. Работает только с уже существующим слотом и текущим LOC1; строки, которых нет в вашей версии игры, останутся английскими.

Опыт этого проекта, который сэкономит вам время, собран в [docs/translation-workflow.md](docs/translation-workflow.md): почему длинные строки с разметкой нужно давать модели посильнее, как ловится разнобой терминов между батчами и какие три класса дефектов видно только глазами на скриншотах.

(версия 1607, включая Enterprise 2016 LTSC) и Windows 11. Отдельный .NET Runtime

Сам русификатор запускается на любом Mac: на Intel он объяснит это словами, а если подключён телефон Android с игрой — предложит поставить перевод на него.

## Установка на Android

Начиная с Android 11 одно приложение не может менять файлы другого. Обойти это на самом устройстве можно только с root; без него в дело вступает компьютер — но собирает перевод всё равно телефон, компьютер лишь передаёт файлы туда и обратно. Ставить ничего не надо: помощник скачивает всё сам.

**В любом способе** сначала выберите в игре **украинский** язык, дождитесь загрузки текста и полностью закройте игру. Русский текст занимает украинскую ячейку — она единственная кириллическая в игре.

### Способ 1 — только устройство (нужен root)

Установите APK, откройте «Русификатор Invokers», нажмите «Установить перевод» и разрешите root-доступ.

### Способ 2 — эмулятор на компьютере (BlueStacks и подобные)

Самый короткий путь: эмулятор работает на том же компьютере, поэтому нет ни кабеля, ни драйверов, ни кода сопряжения, ни окна «Разрешить отладку». Помощник сам перебирает локальные порты и читает настройки BlueStacks.

С включённым root компьютер не нужен вовсе: перетащите APK на окно эмулятора и действуйте по способу 1. Root включается в «Настройки» → «Дополнительно» → «Root-доступ», после чего эмулятор надо перезапустить.

Без root:

1. BlueStacks: «Настройки» → «Дополнительно» → **«Android Debug Bridge»** — включите и нажмите «Сохранить». Там же видна строка вида `127.0.0.1:5555`.
2. Распакуйте `Rusifikator-Invokers-ANDROID.zip` и запустите **«Русификатор-Android.cmd»**.
3. Выберите пункт **«эмулятор на этом компьютере»**, затем «Установить перевод».

Если эмулятор не нашёлся, помощник спросит порт — возьмите его из той же строки настроек. При нескольких запущенных окнах оставьте одно: помощник берёт первое ответившее.

Проверено на подставном устройстве, повторяющем поведение эмулятора; на живом BlueStacks не тестировалось.

### Способы 3 и 4 — телефон по Wi-Fi или кабелем

1. Распакуйте `Rusifikator-Invokers-ANDROID.zip` и запустите **«Русификатор-Android.cmd»** на Windows либо **«Русификатор-Android.command»** на Mac (в первый раз — правой кнопкой → «Открыть»).
2. Включите режим разработчика: «Настройки» → «Сведения о телефоне» → «Сведения о ПО» → семь раз нажмите «Номер сборки».
3. В «Параметрах разработчика» включите **«Отладка по Wi-Fi»** либо **«Отладка по USB»**.
4. Выберите в программе соответствующий пункт и нажмите «Установить перевод».

По Wi-Fi телефон и компьютер должны быть в одной сети; программа попросит адрес и код из «Отладка по Wi-Fi» → «Подключение устройства с помощью кода сопряжения» — код живёт около минуты. На Windows этот способ надёжнее кабеля: не нужны драйверы.

По кабелю нужен провод для передачи данных, а на телефоне — «Разрешить отладку по USB» с галочкой «Всегда разрешать». На **Samsung** предварительно выключите **Auto Blocker**, на **Xiaomi** включите ещё и «Отладка по USB (настройки безопасности)».

### Вернуть оригинал

В той же программе: пункт 2 вернёт сохранённую копию, пункт 3 заставит игру скачать оригинал с сервера. Из терминала то же делает `scripts/android-patch.sh` командами `status`, `apply`, `restore`, `reset`.

Подробный разбор: [docs/android-client.md](docs/android-client.md).

## Установка на ПК

Для игры, установленной на сам компьютер. Патчер сам находит стандартный кэш локализации и определяет версию игры. Затем он выбирает опубликованный точный профиль либо строит локально закреплённый профиль совместимой ревизии; запись разрешается только после проверки текущих EN/UK/stamp, структуры LOC1, каталога, итогового файла и всех счётчиков композиции.

> **Перед русификацией:** выберите в игре **украинский язык**, дождитесь загрузки текста, затем полностью закройте игру и лаунчер, включая его значок в системном трее.

1. Скачайте установщик `InvokersRu-…-win-x64.exe` из [последнего выпуска](https://github.com/Braintfy/ruslocal-invokers/releases/latest) и установите приложение. Права администратора не требуются.

2. В игре зайдите в настройки и выберите **украинский** язык. Дождитесь загрузки текста.

   Русский текст подставляется в украинскую ячейку — она единственная кириллическая в игре.

3. Полностью закройте игру и лаунчер, включая значок лаунчера в системном трее.

4. Запустите **InvokersRu** из меню «Пуск», нажмите **«Проверить»**, затем **«Установить русификацию»**.

Патчер показывает обнаруженную версию, выбранный режим, число русских и оставшихся английских строк, а также состояние резервной копии. При несовпадении он отдельно называет компонент, текущее и ожидаемое значение — например EN/UK content и revision — и объясняет, устарели ли именно данные перевода, изменилась ли структура или нарушено локальное состояние. Новый номер версии сам по себе не блокирует запись: для поддерживаемой структуры LOC1 используется режим совместимой ревизии. Запись блокируют запущенная игра или лаунчер, повреждённые/недоверенные данные, незавершённая операция либо изменение формата, пути, языкового слота, семейства контента или порядка ключей. Принудительного и нечёткого сопоставления нет.

Оригинальный украинский файл сохраняется в `%LOCALAPPDATA%\InvokersRussian\runtime-cache`; кнопка **«Восстановить оригинал»** возвращает только резервную копию, связанную с текущей версией игры.

## Установка на macOS

1. Откройте DMG и перетащите **«Русификатор Invokers»** в папку «Программы».

2. **Первый запуск — правой кнопкой по значку → «Открыть»**, затем подтвердите. Обычный двойной клик система заблокирует: у приложения нет платной подписи Apple. Это нужно сделать один раз.

3. Запустите игру, зайдите в настройки и выберите **украинский** язык. Дождитесь загрузки и полностью закройте игру (Cmd+Q).

   Русский текст подставляется в украинскую ячейку — она единственная кириллическая в игре.

4. Запустите русификатор и нажмите **«Установить перевод»**.

5. Приложение попросит **доступ к данным игры** и само откроет нужный раздел настроек. Включите переключатель напротив «Русификатор Invokers» — установка продолжится сама, возвращаться в приложение не нужно.

   Если переключателя нет в списке, нажмите «+» и выберите приложение в папке «Программы».

## Одно правило, которое нельзя нарушать

**Не открывайте выбор языка в настройках игры.**

При выборе любого языка клиент заново скачивает языковой файл с сервера и стирает перевод. Язык должен остаться украинским. Если перевод внезапно пропал — почти всегда причина именно в этом; просто установите его заново.

## Обновления и обновление игры

**Windows 3.1.1:** приложение проверяет закреплённый канал данных на GitHub. Каталог перевода и необязательные точные профили игры подписываются отдельным ключом проекта, поэтому обычное обновление перевода не требует скачивать новый EXE. Патчер проверяет подпись, последовательность выпуска, размеры и SHA-256 каждого файла до использования. Точный профиль предпочтителен; без него совместимая ревизия обслуживается локально закреплённым планом с построчной проверкой EN+UK.

Если у вас установлен старый Windows-патчер 3.0 или уже опубликованный 3.1.0,
один раз замените его на 3.1.1. Версия 3.0 ещё не знает протокол канала данных,
а 3.1.0 не содержит исправление для Windows 10 1607 и новый совместимый режим
ревизий. После перехода обычные совместимые обновления перевода приходят без
замены EXE.

**macOS** подтягивает свежий перевод и обновляемую часть драйвера сам, принимая загрузку только при совпадении опубликованной контрольной суммы. Переустанавливать приложение и заново выдавать доступ к диску при этом не нужно — обновляемая часть лежит вне пакета. Новый DMG требуется редко и только когда приложение прямо об этом скажет; тогда доступ к диску придётся выдать заново, потому что система привязывает его к конкретной сборке: в списке «Полный доступ к диску» выделите строку, нажмите **«−»**, затем **«+»** и выберите приложение заново.

Отключить самообновление: `touch ~/Library/Application\ Support/InvokersRu/no-self-update`

На macOS переустанавливать приложение и заново выдавать доступ к диску обычно не нужно: обновляемая часть лежит вне приложения. Загруженное обновление принимается только при совпадении опубликованной контрольной суммы.

Отключить самообновление можно так:

```sh
touch ~/Library/Application\ Support/InvokersRu/no-self-update
```

Скачивать новый DMG нужно редко — только когда приложение прямо об этом скажет. Так бывает, если менялся сам запускающий модуль. В этом случае разрешение на доступ к диску придётся выдать заново: система привязывает его к конкретной сборке. Достаточно в списке «Полный доступ к диску» выделить строку, нажать **«−»**, затем **«+»** и выбрать приложение заново.

## После обновления игры

Обновление игры обычно возвращает официальный языковой файл. На Windows снова выберите украинский язык, дождитесь загрузки, полностью закройте игру и лаунчер, затем нажмите **«Проверить»**. Патчер сначала ищет подписанный точный профиль. Если его нет, но EN/UK/stamp образуют поддерживаемое семейство raw LOC1 schema 4 с ожидаемыми языковыми слотами и одинаковым порядком ключей, он строит локально закреплённый профиль совместимой ревизии и предлагает **«Обновить русификацию»**. Русскими становятся только строки с точным совпадением `source_sha256` и `hint_sha256`; новые, изменённые и отсутствующие строки остаются английскими, а служебные null-записи сохраняют базовое значение.

На macOS и Android после совместимого обновления запустите русификатор и установите перевод ещё раз.

Новый EXE или точный профиль требуется только если изменилась граница совместимости: путь к кэшу, формат/schema LOC1, языковой слот, семейство GUID, структура или порядок ключей. Если изменился только текст, часть строк временно останется английской до обновления каталога.

## Как вернуть оригинал

На Windows и Mac — кнопка **«Восстановить оригинал»**. На Android — пункты 2 и 3 в программе для компьютера. Windows-патчер разрешает восстановление только для точной резервной копии, связанной с текущим состоянием.

Удалить русификатор с Mac полностью: «Восстановить оригинал», затем удалить приложение и папку `~/Library/Application Support/InvokersRu`.

## Риски

- Перевод машинный и живым редактором не вычитан. Формулировки могут быть неточными, особенно в длинных описаниях механик. Числа, проценты и длительности сохраняются в точности — их проверяет автоматический контроль.
- Часть текста приходит с сервера, а не из файла игры: витрина магазина, тексты акций и событий останутся украинскими. Изменить это со стороны клиента нельзя.
- Проект неофициальный и не связан с HitZone Inc. Актуальные правила игры требуют осторожности с изменением клиента; используйте на свой риск.
- Изменяется ровно один файл — кэш локализации в папке данных игры:
  на Windows `%USERPROFILE%\AppData\LocalLow\Hit_Zone\Invokers\i18n\dl_uk_UA.bin`,
  на macOS `~/Library/Containers/<UUID>/Data/Documents/i18n/dl_uk_UA.bin`,
  на Android `/sdcard/Android/data/hitzone.anima.spirit.guardians/files/i18n/dl_uk_UA.bin`.
  Сама игра, её подпись и защита не затрагиваются: файл лежит вне подписанного пакета.
- На macOS приложению нужен полный доступ к диску — иначе система не даёт ему прочитать файлы игры. На Android нужна отладка по USB или Wi-Fi, её стоит выключить, когда перевод установлен.

Правовой статус описан в [NOTICE.md](NOTICE.md).

## Если что-то пошло не так

На macOS журнал работы лежит в `~/Library/Application Support/InvokersRu/patcher.log`.

| Симптом | Причина и решение |
| --- | --- |
| «Не удалось создать резервную копию» (Mac) | Нет доступа к диску. Выдайте его в настройках; если переключатель уже включён — удалите строку кнопкой «−» и добавьте приложение заново. |
| «Украинский текст ещё не загружен» | Язык в игре не переключён на украинский, либо файл не докачался. |
| Перевод пропал сам | Открывали выбор языка в игре или игра обновилась. Установите заново. |
| «Не удалось собрать перевод для этой версии игры» | Игра обновилась, перевод ещё не адаптирован. |
| Телефон не появляется в программе (Android) | Не включена отладка, не нажато «Разрешить» на экране телефона, либо на Samsung включён Auto Blocker. По кабелю на Windows могут не встать драйверы — тогда используйте способ по Wi-Fi. |
| «Файл текста уже кем-то подменён» (Android) | Перевод ставили другим способом, а оригинала у программы нет. Выберите пункт 3 — игра скачает оригинал сама. |
| «Телефон не ответил за пять минут» (Android) | Экран телефона был заблокирован. Разблокируйте его и повторите. |

## Для разработчиков

Кросс-платформенный CLI на .NET 10 без внешних зависимостей.

Версия SDK закреплена в `global.json` (10.0.302, `rollForward: latestPatch`). С другой сборкой `dotnet` откажется собирать — поставьте нужную рядом, это не конфликтует с уже установленными:

```sh
curl -sSL https://dot.net/v1/dotnet-install.sh | bash -s -- --version 10.0.302
```

```sh
dotnet build src/InvokersRu.Cli/InvokersRu.Cli.csproj -c Release
dotnet run --project src/InvokersRu.SmokeTests -c Release --no-build -- PATH_TO_PRIVATE_FIXTURES
```

Сборка macOS-приложения и образа:

```sh
./scripts/build-mac-app.sh      # приложение и образ для macOS
./scripts/build-android-apk.sh  # APK без Gradle: aapt2, javac, d8, apksigner
./scripts/build-pc-helper.sh    # архив помощника для компьютера, APK кладётся внутрь
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\publish-windows-preview.ps1 # self-contained Windows payload
```

Скрипт сборки macOS сам считает контрольную сумму драйвера, прописывает её в `config/mac-patcher.json` и удаляет предыдущие образы. Ключ подписи APK лежит вне репозитория, в `~/.config/invokersru/android-release.keystore`, и его нельзя терять: Android отвергает обновление с другой подписью.

### Как это устроено

Игра берёт актуальные таблицы локализации не из своего пакета, а из пользовательского кэша. Перевод подменяет только его.

Публичный overlay `translations/ru_RU.jsonl` не содержит исходного английского текста — только хэши строк и русский перевод:

```json
{"id":"16_HEX","source_sha256":"64_HEX","translation":"Русский текст","status":"draft"}
```

Поле `source_sha256` автоматически обесценивает перевод, если английская строка изменилась в новом обновлении игры.

Приложение устроено так, чтобы разрешение macOS не слетало: точка входа — неизменный бинарный `launcher`, а обновляемый драйвер лежит в `~/Library/Application Support/InvokersRu/runtime/`. Любая правка внутри пакета сменила бы его подпись и отозвала доступ к диску.

### Основные команды

```sh
InvokersRu.Cli inspect FILE                 # разбор LOC1
InvokersRu.Cli roundtrip FILE               # доказать побайтовую пересборку
InvokersRu.Cli cache-status                 # состояние кэша игры
InvokersRu.Cli cache-profile --output FILE  # снять профиль новой версии игры
InvokersRu.Cli jobs --english EN --output JOBS
InvokersRu.Cli import-results --english EN --jobs JOBS --results RES --output NEXT
InvokersRu.Cli validate --english EN --translations CAT --include-draft
InvokersRu.Cli build --english EN --base UK --translations CAT --output OUT --include-draft --raw
InvokersRu.Cli update-status              # состояние подписанного канала данных
InvokersRu.Cli update-refresh             # забрать свежий каталог и профили из канала
```

Подробности по формату, платформам и переводческому конвейеру: [docs/](docs/).

### Новая версия игры

1. Создайте приватный рабочий каталог и снимите профиль: `cache-profile --output work/profiles/runtime-cache-profile.<версия>.json`
2. Постройте diff по `source_sha256`: неизменённые переводы остаются, изменённые становятся устаревшими, новые уходят в `jobs`.
3. Переведите новые строки и влейте через `import-results`.

Оригинальные файлы игры (`*.bin`, `*.bin.br`, `manifest.dat`) в репозиторий не попадают.
