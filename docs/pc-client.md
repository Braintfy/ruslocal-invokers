# ПК-клиент: InvokersRu 3.1.1

Актуальный Windows-патчер — графическое приложение `InvokersRu.Gui.exe` и соседний supervised CLI. Он заменяет старые `install-pc.ps1`, `Русификатор-ПК.cmd` и архив `Rusifikator-Invokers-PC-Game.zip`.

Готовый пакет поддерживает x64 Windows 10 начиная со сборки 14393 (версия
1607, включая Enterprise 2016 LTSC) и Windows 11. Он self-contained: отдельный
.NET Runtime игроку не нужен. Текущий community preview не подписан
Authenticode, поэтому Windows может показать SmartScreen или «Неизвестный
издатель»; сверяйте SHA-256 с GitHub Release.

Публичную версию 3.1.0 нужно один раз заменить на 3.1.1: минимальная версия
Windows и совместимый режим ревизий задаются кодом приложения. После этого
обычные совместимые обновления каталога приходят через подписанный канал без
повторной загрузки EXE, пока патчер прямо не попросит обновить себя.

## Перед установкой перевода

1. Запустите игру и выберите **украинский язык**.
2. Дождитесь полной загрузки украинского текста.
3. Полностью закройте игру и лаунчер, включая значок лаунчера в системном трее.
4. Запустите InvokersRu, нажмите **«Проверить»**, затем **«Установить русификацию»**.

Русский текст занимает украинский языковой слот. После установки не открывайте выбор языка: клиент скачает официальный файл и заменит перевод.

## Что проверяет патчер

- стандартный runtime-кэш `%USERPROFILE%\AppData\LocalLow\Hit_Zone\Invokers\i18n`;
- обнаруженную версию игры, EN/UK LOC1 и stamp версии;
- точные SHA-256 каталога, наблюдаемых EN/UK/stamp и ожидаемого результата;
- резервную копию, журнал незавершённой операции и запущенные процессы;
- совпадение количества русских и fallback-строк с профилем выпуска.

Версия 3.1.1 также проверяет подписанный канал данных на GitHub. Она предпочитает
опубликованный точный профиль, но для новой структурно совместимой ревизии умеет
локально закрепить наблюдаемые EN/UK/stamp, каталог, output, keyset и counts. В
этом режиме переводятся только строки с точным совпадением английского исходника
и украинской подсказки; новые или изменённые строки остаются английскими.

Сам по себе неизвестный номер версии не является отказом. Запись блокируется,
если изменились фиксированный путь, raw LOC1 schema 4, языковые слоты EN=1/UK=8,
доверенное семейство content GUID или одинаковый упорядоченный набор ключей, а
также при повреждённом состоянии или недоверенном каталоге. Режима `force` и
нечёткого сопоставления нет. Подробности: [windows-smart-patcher.md](windows-smart-patcher.md).

## Запись и восстановление

GUI не меняет файлы самостоятельно. Он получает строгий JSON-план от соседнего CLI и вызывает только `cache-apply`, `cache-restore` или `cache-recover`. CLI использует mutex, lock-файл, immutable backup, фазовый журнал, повторную проверку исходных файлов и атомарную замену на том же NTFS-томе.

Оригинал хранится вне игры в `%LOCALAPPDATA%\InvokersRussian\runtime-cache`. Кнопка **«Восстановить оригинал»** доступна только когда состояние и резервная копия точно относятся к активному профилю.

## Сборка Windows-пакета

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\publish-windows-preview.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\build-installer.ps1 `
  -InputDirectory .\work\publish\windows-3.1.1-preview `
  -AppVersion 3.1.1-preview `
  -OutputDirectory .\work\installer-output
```

Публичный payload не содержит CMD/PowerShell-обёрток. Он self-contained, не требует отдельной установки .NET или прав администратора. Правила упаковки и подписи: [windows-release-safety.md](windows-release-safety.md).
