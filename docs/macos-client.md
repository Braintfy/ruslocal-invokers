# Нативный клиент macOS

Обновлено 30 сентября 2026 года по локальным файлам нативного клиента: официальный лаунчер `1.0.319`, игра `0.61.1506`.

## Поддерживаемая установка

Официальный лаунчер устанавливает игру сюда:

```text
~/Library/Application Support/zone.hitzone.invokers.launcher/game/Invokers.app
```

Нативный клиент хранит скачанные таблицы локализации вне подписанного приложения:

```text
~/Library/Application Support/hitzone.anima.spirit.guardians/i18n/
```

Проверены именно скачанные `dl_en_US.bin` и `dl_uk_UA.bin`, а не встроенные таблицы приложения. Оба файла относятся к LOC1 `Prod_0.61.1_3`, содержат 42 673 записи и в этом выпуске не сопровождаются `.ver`. Сборка текущего каталога по этим файлам дала:

- 42 451 русскую строку;
- 2 английских fallback;
- 220 пустых записей исходной таблицы.

Номер игры `0.61.1506` и версия содержимого LOC1 `Prod_0.61.1_3` описывают разные вещи. В оболочке показывается версия языковых таблиц. При крупном обновлении нужно запустить игру сначала на английском, затем после полного перезапуска на украинском языке, каждый раз дожидаясь главного меню. Это загружает обе актуальные таблицы.

## Причина сбоя старого установщика

Версия 2.7.0 всегда предпочитала старый контейнер iOS-on-Mac:

```text
~/Library/Containers/<UUID>/Data/Documents/i18n/
```

После выхода нативного клиента этот каталог остался на версии `0.60.1247`, а игра стала читать новый каталог Application Support. Патчер сообщал об успешной установке, но менял неиспользуемый файл.

Текущий скрипт `2.11.0` в оболочке `3.1.0`:

- всегда выбирает нативный каталог при его наличии, даже если старый iOS-контейнер сохранился с другим номером версии;
- на запасных путях определяет выпуск по LOC1, а `.ver` использует лишь для старых файлов;
- показывает выбранный клиент, версию таблиц, активный язык и путь до изменения;
- проверяет согласованность скачанных английской и украинской таблиц; для числового семейства `0.61` допускает разные ревизии внутри одного `content_guid` (например, EN `Prod_0.61.1_3` и UK `Prod_0.61.1_5`);
- хранит отдельное состояние и резервную копию для каждого кеша;
- распознаёт процесс нативной игры и не пишет файл во время её работы;
- при нажатии **«Проверить»** также проверяет обновление самого скрипта. Совместимая установленная оболочка получает его без замены приложения.

Переменная `INVOKERSRU_CACHE_ROOT` остаётся явным override для тестирования и нестандартных установок.

## Почему используется `uk_UA`

Русский текст подставляется в украинский слот: это кириллическая локаль, уже поддерживаемая шрифтами игры. До установки игрок должен выбрать украинский язык и дождаться появления `dl_uk_UA.bin`. После установки выбор языка открывать нельзя — клиент перекачивает официальный файл.

Запуск с `-language en_US` показывает английский независимо от содержимого украинского файла и при выходе сохраняет locale id `1`. Это не ошибка сборки перевода; активным должен оставаться `uk_UA`. Патчер сохраняет id `8` после установки, а кнопка запуска открывает нативную игру с `-language uk_UA`.

## Безопасность изменения

Приложение не меняет `Invokers.app`. Оно заменяет только `dl_uk_UA.bin` в пользовательском кеше, предварительно создавая резервную копию с именем по SHA-256 содержимого. Запись выполняется атомарно. Восстановление допускается только при совпадении текущего файла с SHA-256 перевода, установленного этим патчером, и резервной копии с SHA-256 оригинала. Если игра уже скачала новый официальный файл, кнопка восстановления недоступна и старый файл поверх него не записывается. При установленном переводе статус также сверяет текущую английскую таблицу с сохранённым хешем и сообщает об обновлении.

Preferences клиента могут содержать токены аккаунта, идентификаторы и email. Их нельзя добавлять в репозиторий, журнал или issue.

Скрипт проверяет выбранный кеш на файлы подписей и контрольных сумм локализации, а найденное `Invokers.app` — на известные компоненты античита. При обнаружении такого признака или ошибке чтения проверяемой папки установка останавливается; причина и путь записываются в журнал. Проверка повторяется непосредственно перед заменой языкового файла. Обычная подпись macOS (`_CodeSignature/CodeResources`), `.src`, старые `.ver` и более новая версия клиента сами по себе установку не блокируют.

Проверка не отключает и не обходит защиту. Восстановление своего перевода доступно при закрытой игре и точном совпадении его файла с сохранённым состоянием. Не удаляйте найденные подписи или компоненты защиты: дождитесь проверки совместимости. Отсутствие известных локальных признаков не гарантирует отсутствия банов — неизвестные механизмы и серверные ограничения так проверить невозможно. После каждого обновления игры проверку нужно выполнить снова.

## Проверки

```bash
scripts/test-mac-patcher.sh
scripts/build-mac-app.sh
```

Первый тест проверяет выбор между нативным и старым кешем, override, изоляцию state, распознавание защиты, повторную проверку перед записью и доступность восстановления. Его файловые сценарии также запускаются в Bash на Linux; Cocoa-интерфейс и сборка DMG проверяются на macOS. Сборщик создаёт универсальное Cocoa-приложение `arm64 + x86_64`, включает self-contained CLI и формирует DMG.
