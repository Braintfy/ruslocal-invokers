InvokersRu 3.1.1 Preview
========================

Русификатор Invokers: Titan Legacy для Windows.

Поддерживается x64 Windows 10 начиная со сборки 14393 (версия 1607, включая
Enterprise 2016 LTSC) и Windows 11. Отдельно устанавливать .NET не требуется.

Если у вас уже установлен публичный preview 3.1.0, один раз обновите его до
3.1.1: поддержка старых сборок Windows 10 и совместимый режим ревизий требуют
нового кода. Дальше обычные совместимые обновления перевода приходят через
подписанный канал без повторного скачивания EXE, пока сам патчер не сообщит иное.

Эта preview-сборка содержит точный профиль клиента 0.60.1247 и проверяет
подписанный канал данных проекта на GitHub. Точный профиль предпочтителен, но
новый номер версии сам по себе не блокирует установку: для поддерживаемого raw
LOC1 schema 4 патчер локально закрепляет текущие EN/UK/stamp, каталог, результат
и counts. Русскими становятся только строки с точным совпадением английского
исходника и украинской подсказки; новые или изменённые остаются английскими. Если
изменятся путь, формат, языковой слот, content family или layout, патчер попросит
обновить приложение.

Патчер не завершает процессы игры, не внедряется в них и не запрашивает права
администратора. Загруженные данные принимаются только после проверки цифровой
подписи канала, версии последовательности, размеров и контрольных сумм.

Перед русификацией выберите в игре украинский язык и дождитесь полной загрузки
текста. Затем полностью закройте игру и лаунчер, включая значок лаунчера в
системном трее. Патчер сам проверит версию, сохранит проверенную резервную копию
и покажет результат операции.

В комплекте этой версии каталог содержит 41 037 русских строк из 41 292. Одна
строка остаётся английской, ещё 254 записи пусты или используют базовое значение.
Точное покрытие всегда показывается в окне до установки.

Текущий публичный preview пока намеренно выпущен без Authenticode-подписи, поэтому
Windows может показать SmartScreen или «Неизвестный издатель». Сверяйте SHA-256
установщика и commit с данными GitHub Release. Подпись EXE доверенным сертификатом
запланирована позже; подпись канала переводов защищает данные, но не заменяет
Authenticode. Контрольные суммы payload находятся в PAYLOAD-SHA256.json.
